# Weather Intelligence Dashboard

A modern, full-stack weather application built with **React**, **TypeScript**, **Tailwind CSS**, and **Express**. Powered by real-time meteorological metrics from the **Open-Meteo API** and personalized planning insights generated by **Google Gemini AI**.

---

## 🌟 Key Features

- **Global City Search & Geocoding**: Autocomplete location search powered by Open-Meteo Geocoding API with full keyboard navigation (arrow keys & Enter).
- **Current Weather Metrics**: Comprehensive live statistics including ambient temperature, "feels like" temperature, humidity, wind direction & gusts, UV index, surface pressure, cloud cover, and daily rainfall totals.
- **Dynamic Sunrise & Sunset Trackers**: Sun position progress bar calculated in real time according to local timezone data.
- **Interactive 24-Hour Hourly Forecast**: Recharts visual graphs with toggleable tabs for Temperature, Rain Probability, and Wind Speed trends.
- **7-Day Weather Forecast**: Weekly temperature ranges with visual thermal bars and detailed day-by-day modal overviews.
- **AI Planning & Recommendations**: Gemini AI-powered activity suitability index (jogging, outdoor dining, sports), travel advisories, clothing recommendations, and interactive custom AI Q&A.
- **Favorites & Location Management**: Instant switching between quick cities and saved user locations with local persistence.
- **Unit Customization**: One-click temperature toggle between Celsius (°C) and Fahrenheit (°F).
- **Frosted Glass UI Aesthetic**: Translucent glassmorphism visual hierarchy with subtle background glow animations.

---

## 🛠️ Tech Stack

- **Frontend**: React 18, TypeScript, Tailwind CSS, Recharts, Lucide React icons
- **Backend / Server**: Express.js, Node.js, `tsx` / `esbuild`
- **APIs**:
  - **Open-Meteo Geocoding API** (`https://geocoding-api.open-meteo.com/v1/search`)
  - **Open-Meteo Forecast API** (`https://api.open-meteo.com/v1/forecast`)
  - **Google Gemini API** (`@google/genai` SDK)

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+)
- npm or bun

### Environment Variables

Copy `.env.example` to `.env` and provide your Gemini API key:

```env
GEMINI_API_KEY=your_gemini_api_key_here
```

### Installation & Execution

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Start Development Server**:
   ```bash
   npm run dev
   ```
   The application will start on `http://localhost:3000`.

3. **Build for Production**:
   ```bash
   npm run build
   npm start
   ```
